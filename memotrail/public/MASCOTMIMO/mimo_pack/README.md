# Mimo — MemoTrail mascot starter pack

This pack contains the approved Mimo **concept sheet** and an animation specification. It is NOT a production-ready transparent sprite-sheet pack: the concept sheet includes a background, varying frame dimensions, and decorative elements. Do not crop the concept board and treat the crops as pixel-perfect animation frames.

## Visual identity
Cream bunny, floppy ears, lavender scarf, small Polaroid camera, soft rounded 3D/clay look.

## Intended animations
idle (8 frames, 8 fps), blink (4 frames, 8 fps), wave (8 frames, 10 fps), walk (8 frames, 12 fps), happy (8 frames, 12 fps), thinking (6 frames, 8 fps), camera (8 frames, 10 fps), celebrate (10 frames, 12 fps), sleep (6 frames, 6 fps).

## Production asset format
One transparent PNG spritesheet per action; horizontal strip, identical canvas size per frame (suggested 256 x 256 px), character centered and scale consistent, no labels, no background. A JSON manifest should describe frameWidth, frameHeight, frames, fps, loop for each sheet.

## Integration
Copy the reference image into your project as a design reference, not as an animated asset. Follow the accompanying Codex prompt. Use a static Mimo reference preview or a simple CSS animation until production spritesheets are ready.
