# Mimo Complete Sprite Pack

14 transparent horizontal PNG sprite sheets. Each sheet: 8 frames, 256x256 px per frame (2048x256 total). The files are **new simplified 2D Mimo illustrations**, not exact replicas of the earlier AI-generated 3D concept. These are genuine separately rendered transparent frames with modest pose/expression changes. Some actions are stylized rather than fully hand-animated.

Animations: idle, blink, wave, walk, happy, sad, cry, thinking, camera, celebrate, sleep, surprised, envelope, memory_jar.

Use manifest.json for fps/loop/frame counts. Use CSS background-position steps(8) with background-size: 800% 100%, or crop frames with canvas. Keep frame dimensions fixed.
